# Gemini Windows Application

A fast and convenient Windows application that brings the Gemini AI experience directly to your desktop.

Boost your productivity by accessing Gemini with a single click, without getting lost in browser tabs.

## 🚀 Features
* **Quick Access:** Instant connection to Gemini directly from your desktop.
* **User-Friendly Interface:** A clean and simple design optimized for the Windows environment.
* **Easy Installation:** Install in seconds with a single `.msi` file.

## 📥 Installation
To download and start using the application right away:

1. Go to the **[Releases](https://github.com/Utku92/Gemini-Windows-Application/releases)** section on the right side of the page.
2. Download the `GeminiSetup.msi` file from the latest release.
3. Run the downloaded file to complete the installation.
